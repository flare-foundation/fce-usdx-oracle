Served beside a keeper, this page reads /cycles.jsonl — the file that keeper is writing — every 30 seconds, and renders it in your browser; nothing is sent anywhere else. Each machine signs a value at its own scale and the keeper records it rendered, so a price here is the number the machine signed; the page reads the precision off the record rather than assuming it. The store takes the median of the contributors, which is what the chart plots, and each contributor's own price stays in the row's detail. race_lost counts as a cycle that advanced the feed — with two or more keepers exactly one submission wins, and the rest are correct behaviour, not failures. Feed age is measured from storeObservedAtAfter, the store's own reading at the end of a cycle. Transaction and address links go to the Coston explorer.
